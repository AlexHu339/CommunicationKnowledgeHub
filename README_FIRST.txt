通信工程知识地图与考研、电赛、AI学习助手 v1.0

推荐安装位置：D:\CommunicationKnowledgeHub

首次使用：
1. 将完整压缩包解压到 D:\CommunicationKnowledgeHub（不要只复制 program）。
2. 双击 setup.bat，等待 Python、前端、OCR 和 Playwright 安装完成。
3. 双击 start.bat。浏览器会自动打开，首次进入可视化配置向导。
4. API 配置可以跳过；406 个去重后的知识主题、笔记、复习、本地 OCR、网络检查和备份仍可使用。
5. 双击 stop.bat 关闭。发生问题时运行 diagnose.bat。

真实 API Key 不包含在交付包中。请只通过网页“API服务配置”填写。

内容说明：旧版为了凑数量拆出的 594 张机械重复卡已合并，并保留旧 ID 跳转兼容。406 个真实主题均已导入自然、通俗的完整解释；“换一批”只读取本地数据库，不会调用或收费。
