# 用户指南

## 首次启动

将目录放到 `D:\CommunicationKnowledgeHub`，运行 `setup.bat` 后再运行 `start.bat`。本机访问免登录；只有在设置中开启局域网模式并重启后，手机才可通过页面显示的局域网地址访问，且必须登录。

首次配置向导允许跳过 AI。DeepSeek、OpenAI 官方和第三方 OpenAI 兼容服务均在网页配置，密钥不会回显。

## 日常使用

- “今日认识 8 个”从 SQLite 选卡，“换一批”不调用 AI。
- 卡片状态、收藏、笔记和复习日期立即保存到 SQLite。
- 卡片正文使用连续、通俗的文章式解释；只在确实需要时出现“背景、类比、用途、易错点”等小节。
- “DeepSeek 扩充知识”才调用 AI，结果先进入“内容审核”，确认后才进入正式知识库。
- 站内不保存普通 AI 问答；“AI 网页入口”可打开 ChatGPT 或 DeepSeek 官方网页。
- “图片与 OCR”在本机执行，不需要 API Key，也不会自动上传图片。识别后可自行修正、复制，再决定是否粘贴到外部 AI。
- 网络更新默认不调用 AI；只有发现相对上次基线发生变化的内容，才进入“内容审核”。
- `backup.bat` 创建不含密钥的备份；将合法备份 ZIP 拖到 `restore.bat` 上恢复。

## 内容审核是什么

它是正式知识库前的一道安全门，只存放 AI 生成、网页更新或批量导入的候选内容。你可以查看来源和正文后选择“确认入库”或“忽略”。首次记录某个网站时只建立比较基线，不再显示成“新增公告”。

## 关闭与故障

使用 `stop.bat` 关闭，避免直接结束整个终端。故障时运行 `diagnose.bat`，日志位于 `userdata/logs` 且不会记录完整授权头或密钥。
