# AI 配置与隐私

网页“API服务配置”把本机服务商和模型能力写入 `private/ai_providers.yaml`；API Key 经本地后端写入 `private/secrets.env`。两者都不进入浏览器存储、SQLite、日志、导出或 Git。

模型能力状态包括已验证支持、已验证不支持、未测试、测试失败和需要手动指定。同步模型列表只同步 ID。每次调用前显示发送摘要；DeepSeek 未验证视觉能力时不会收到原图。

多轮消息保存在 SQLite，只发送摘要与最近若干轮；删除会话会级联删除本地消息，不保存隐藏推理过程。价格未知时只显示 token，不伪造精确费用。

OpenAI Responses 请求固定使用 `store:false`，由本站 SQLite 自行管理多轮上下文。“极高”思考档位映射为 API 的 `xhigh`；如果模型不支持，应在“模型能力测试”中记录为不支持并改用较低档位。

AI 问答中的“是否联网”与 Codex CLI 的认证模式无关：

- Responses 模型只有在“原生联网搜索”短测试通过后，才使用服务商的 `web_search` 工具。
- DeepSeek 或未验证原生搜索的兼容模型，由本站后端先检索公开网页，再将结果连同来源交给模型。
- 关闭开关时，本次问答不会发起网页搜索。

图片选择只有在对应模型的“图片输入”测试通过后才启用。本站后端只接受媒体目录内经过验证的 PNG、JPEG 或 WebP，每次最多4张；浏览器不会直接持有或发送 API Key。

部分第三方 Responses 服务要求非秘密的兼容标记请求头。本站只允许经过白名单验证的 `x-openai-actor-authorization`，不会允许自定义 `Authorization`、Cookie 或其他可能泄密的请求头。HTTP 5xx、401、403、404、405、408、409、425、429 记为“测试失败”，不会误报为“模型已验证不支持”。
