# 来源政策

官方原文、页面快照、抓取日期、哈希和 AI 解释分开保存。HTTP 读取失败才用 Playwright 正常浏览器加载；不破解验证码、不绕过账号/付费墙/访问控制、不高频抓取。动态字段缺失时显示“未找到或待核实”。

外部图片必须本地保存并登记原页面、作者、许可证、下载时间、使用范围和关联知识点。

未明确授予再分发许可的 Wallpaper Engine Workshop 素材只能保存在 `userdata/media/backgrounds` 供用户本机个人使用，并登记作品页与作者信息；不得进入程序发布包、Git仓库或普通导出。网站只加载经选择的静态纹理，不执行第三方场景脚本或播放其音频。
